01

理解概念

回到当时的问题

修改了首页后，怎样在自己的电脑上检查网页和样式？

启动和访问

在 Ubuntu 终端进入站点目录，用 pwd 确认位置，用 ls 确认有 index.html。

已有 Python 3 时，启动本地服务，在 Windows 浏览器打开 http://127.0.0.1:8000/。回到运行服务的终端按 Ctrl+C 停止。

02

把概念放进示例

01预览首页

在站点根目录验证修改后的首页。

  1. 在 Ubuntu 终端启动服务。
  2. 从 Windows 浏览器访问首页。
bash
python3 -m http.server 8000 --bind 127.0.0.1

得到什么
浏览器显示首页，终端记录网页请求。
